## WHAT DOES THIS PROJECT INCLUDE?

This project right now includes:

- An interface similar to the "cal" command
- All weekend days are marked in red. Current day is also marked in white
- CLI arguments support
- A calendar box so the calendar looks way cooler 
- Rigt now, you can pass the month as the second argument (in lowercase)
and the year as the third argument (currently from 1000 to 9999).
EXAMPLES: ./main november 2029
- If you don't pass any valid arguments, the calendar will use
the current month and year
